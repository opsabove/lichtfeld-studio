# LichtFeld Studio

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/opsabove)

A Windows installer for **LichtFeld Studio** — 3D Gaussian Splatting training and viewer.

---

## Requirements

- Windows 10 / 11 (64-bit)
- NVIDIA GPU (recommended)
- CUDA 12 runtime

---

## Installation

Download **LichtFeld_Studio_Setup.exe** from the [Releases](../../releases) page and run it.

---

## Workflow

```
Video footage
      ↓
Frame export tool  →  frames (GPS EXIF optional)
      ↓
COLMAP  →  sparse reconstruction
      ↓
LichtFeld Studio  →  3D Gaussian Splatting
```
